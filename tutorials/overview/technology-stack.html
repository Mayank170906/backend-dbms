BackendDBMS Docs

Technology Stack

Every dependency actually declared in pyproject.toml, why it's there, and where it's used.

Dependency management is uv + pyproject.toml/uv.lock — there is no requirements.txt in this repo.

Core framework

PackageWhyWhere used
django>=6.1.1The web framework and ORM.Everywhere — config/, every app.
djangorestframework>=3.18.1The REST API layer: serializers, viewsets, routers, permissions, throttling.Every apps/*/api/ package.
djangorestframework-simplejwt>=5.5.1JWT issuance/validation, refresh rotation, blacklist.SIMPLE_JWT settings, apps/accounts/api/views.py, config/channels_auth.py.
django-filter>=26.1Declarative queryset filtering on list endpoints.DjangoFilterBackend on most viewsets.
drf-spectacular>=0.30.0OpenAPI schema generation and Swagger UI./api/schema/, /api/docs/.
django-cors-headers>=4.9.0CORS handling for a separately-originated frontend.CorsMiddleware, CORS_ALLOWED_ORIGINS.

Database

PackageWhyWhere used
psycopg[binary]>=3.3.5The PostgreSQL driver (psycopg3).Django's Postgres backend, docker/entrypoint.sh's connection-retry loop.
dj-database-url>=3.1.2Parses a single DATABASE_URL into Django's DATABASES setting.config/settings/base.py.

PostgreSQL itself (not a Python package) is the system of record — chosen specifically for SearchVectorField/GinIndex full-text search and ArrayField, both used directly by real models rather than being unused capabilities.

Async / real-time

PackageWhyWhere used
celery>=5.6.3Background jobs and the scheduled beat jobs.config/celery.py, apps/{accounts,projects,tasks}/tasks.py.
redis>=8.1.0Backing store for cache, Celery broker/result backend, and the Channels layer.CACHES, CELERY_BROKER_URL, CHANNEL_LAYERS.
channels>=4.3.2 / channels-redis>=4.3.0WebSocket support over ASGI, with Redis as the cross-process channel layer.config/asgi.py, apps/{projects,notifications}/consumers.py.
daphne>=4.2.3The ASGI server that actually serves HTTP and WebSocket traffic in production.docker-compose.prod.yml's web command; also first in INSTALLED_APPS so its own runserver override is used in dev.

Deployment / infra

PackageWhyWhere used
whitenoise>=6.12.0Serves compressed, content-hashed static files directly from the Django process — no separate static-file server needed.WhiteNoiseMiddleware, STORAGES["staticfiles"].
python-dotenv>=1.2.3Loads a local .env file in development.config/settings/base.py.
Docker + uvReproducible image build; uv sync --frozen installs exactly what's pinned in uv.lock.Dockerfile.

Render and Supabase are hosted services, not dependencies — see Deployment.

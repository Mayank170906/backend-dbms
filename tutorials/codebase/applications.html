Codebase: Applications

The 9 Django apps under apps/, one paragraph each.

🔑 accounts

Owns the custom User model (AUTH_USER_MODEL = "accounts.User") and every JWT auth endpoint: register, login, logout, refresh, password reset, "me", and a searchable user directory. Every other app's foreign keys to a user point here.

🏢 organizations

The tenant boundary. Organization, Membership (roles OWNER/ADMIN/MEMBER/VIEWER), Team, and TeamMembership. Also owns the one custom management command, seed_data.

🔀 workflows

Per-organization, admin-defined pipelines: Workflow → ordered WorkflowStates → explicit, role-gated WorkflowTransitions. WorkflowService.transition_task is the sole authority for moving a task between states.

📁 projects

Project, ProjectMembership (roles MANAGER/DEVELOPER/VIEWER), ProjectExport. Also owns project statistics (statistics.py, cache-aside via caching.py), full-text search vector maintenance (search.py), the WebSocket consumer for the project activity feed (consumers.py/routing.py), and the CSV export Celery task.

✅ tasks

Task, Label, TaskAssignment. Owns task search-vector maintenance and the two scheduled/async task functions (due-tomorrow notifications, and the signals that invalidate project-statistics cache on any task change).

💬 comments

Comment, scoped to a Task. Owns @username mention parsing and its own search-vector maintenance.

📜 activity

ActivityLog — an append-only audit trail via GenericForeignKey, scoped to an organization and optionally a project. ActivityService.log() is the single write path every other app's service calls into, and it broadcasts to the project WebSocket group via transaction.on_commit().

🔔 notifications

Notification, scoped to a recipient. NotificationService.notify() is called by every other app's service on assignment/mention/transition/export/report events, and broadcasts to the per-user WebSocket group.

🔍 analytics

No models of its own — a thin api/ package exposing SearchView, which runs Postgres full-text search across Project/Task/Comment, each pre-filtered by the caller's real membership.

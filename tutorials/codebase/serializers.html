Codebase: Serializers

Every serializer, its fields, and its custom validation.

accounts
  • UserSerializer — id, username, email, first_name, last_name, avatar, created_at; all read-only.
  • RegisterSerializer — id, username, email, password (write-only, validate_password), first_name, last_name; custom create() calls User.objects.create_user(**validated_data).
  • PasswordResetRequestSerializer — email. PasswordResetConfirmSerializer — uid, token, new_password. LogoutSerializer — refresh.
organizations
  • OrganizationSerializer — id, name, slug, description, owner, created_at, updated_at; read-only: id/slug/owner/created_at/updated_at.
  • MembershipSerializer — nested read-only user = UserSerializer(); id, organization, user, role, joined_at.
  • TeamSerializer — id, organization, name, description, created_at.
projects
  • ProjectSerializer — organization, name, slug, description, owner, status, workflow, created_at, updated_at; read-only id/slug/owner/created_at/updated_at.
  • ProjectMembershipSerializer — nested read-only user.
  • ProjectExportSerializer — file_url = SerializerMethodField() (builds an absolute URI from request context); all fields read-only.
tasks
  • LabelSerializer — id, project, name, color.
  • TaskSerializer — assignees PK-only read-only + nested read-only assignees_detail/created_by_detail; labels writable; read-only id/created_by/workflow_state/created_at/updated_at. Custom validate_labels(value) rejects labels from a different project. Custom validate(attrs) rejects changing project on update.
  • TaskAssignSerializer — user_id. TaskTransitionSerializer — to_state_id.
comments

CommentSerializer — nested read-only author_detail; read-only id/task/author/created_at/updated_at.

workflows
  • WorkflowStateSerializer — read-only id/workflow/slug.
  • WorkflowTransitionSerializer — read-only id/workflow/created_at.
  • WorkflowSerializer — nested read-only states/transitions.
activity

ActivityLogSerializer — actor via SlugRelatedField(slug_field="username"), object_type from content_type.model; all read-only.

notifications

NotificationSerializer — id, notification_type, message, object_id, is_read, created_at, read_at; all read-only.

analytics

SearchResultSerializer(Serializer) exists only for OpenAPI schema documentation — the view builds its actual response manually.

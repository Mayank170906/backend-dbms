workflows

Workflow

organization FK(CASCADE, related_name="workflows"), name, description, created_at, updated_at. Meta: ordering=["name"], UniqueConstraint(["organization","name"]).

WorkflowState

workflow FK(CASCADE, related_name="states"), name CharField(100), slug SlugField(100), order PositiveIntegerField, is_initial/is_terminal BooleanField(default=False). Meta: ordering=["order"], UniqueConstraint(["workflow","slug"]), UniqueConstraint(["workflow","order"]).

activity

ActivityLog

actor FK(User, SET_NULL, null/blank, related_name="activity_logs"), action (Action choices: task.created / task.assigned / task.status_changed / comment.added / project_membership.changed / workflow.changed), content_type FK(ContentType, CASCADE), object_id PositiveBigIntegerField, target = GenericForeignKey("content_type","object_id"), organization FK(CASCADE, related_name="activity_logs"), project FK(CASCADE, null/blank, related_name="activity_logs"), metadata JSONField(default=dict, blank=True), created_at.

Meta: ordering=["-created_at"], indexes on ["organization","created_at"], ["project","created_at"], ["content_type","object_id"].

Immutable by design: save() raises ValueError if pk is not None (no updates); delete() always raises ValueError (no deletes) — see OOP / Class Design.

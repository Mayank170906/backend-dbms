Codebase: Views

Every view/viewset class, its base class, and its custom actions.

All authentication relies on DRF's global default (JWTAuthentication) — no view sets authentication_classes individually.

accounts
  • RegisterView(generics.CreateAPIView) — AllowAny, throttle scope "auth".
  • LoginView(TokenObtainPairView) — AllowAny, throttle scope "auth".
  • LogoutView(APIView) — IsAuthenticated; blacklists the submitted refresh token.
  • MeView(generics.RetrieveAPIView) — IsAuthenticated; get_object() returns request.user.
  • UserViewSet(mixins.ListModelMixin, mixins.RetrieveModelMixin, GenericViewSet) — IsAuthenticated; SearchFilter on username/email.
  • PasswordResetRequestView / PasswordResetConfirmView(APIView) — AllowAny, throttle "auth"; the request view always returns 200 regardless of whether the account exists.
organizations
  • OrganizationViewSet(ModelViewSet) — permissions [IsAuthenticated, IsOrganizationAdmin]; queryset filtered to memberships__user=request.user; perform_create → OrganizationService.create_organization; @action(detail=True, methods=["get","post"], url_path="members").
  • TeamViewSet(ModelViewSet) — IsAuthenticated; filterset_fields=["organization"]; scoped to the caller's orgs; perform_create checks membership then calls TeamService.create_team.
projects

ProjectViewSet(ModelViewSet) — permissions [IsAuthenticated, IsProjectManager]; filterset_fields=["organization","status"]; queryset scoped by memberships__user; perform_create → ProjectService.create_project. Custom actions: members (GET/POST), activity (GET), statistics (GET), export (POST, 202 + Celery task), exports (GET).

tasks
  • TaskViewSet(ModelViewSet) — IsAuthenticated; custom TaskFilter; search_fields=["title","description"]; queryset scoped by project__memberships__user with select_related/prefetch_related to avoid N+1. Actions: assign, transition, comments (GET/POST).
  • LabelViewSet(ModelViewSet) — IsAuthenticated; filterset_fields=["project"]; scoped by project membership.
workflows

WorkflowViewSet(ModelViewSet) — IsAuthenticated; filterset_fields=["organization"]; scoped by org membership. Actions: add_state (POST states/), add_transition (POST transitions/).

notifications

NotificationViewSet(mixins.ListModelMixin, mixins.RetrieveModelMixin, GenericViewSet) — IsAuthenticated; queryset filtered to recipient=request.user. Actions: mark_read (detail POST), mark_all_read (list-level POST, url_path="read-all").

analytics

SearchView(APIView) — IsAuthenticated; GET /?q= runs SearchQuery/SearchRank across Project/Task/Comment, each scoped to caller's org/project membership, capped at 20 results each, ordered by rank.

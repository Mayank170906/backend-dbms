Codebase: Utilities

The small, real helper functions — kept short because that's all there is.

This project keeps genuinely reusable helpers to a minimum rather than building a speculative utils.py per app. What actually exists:

  • env_bool(name, default=False) and env_list(name, default="") in config/settings/base.py — parse environment variables consistently (e.g. "1"/"true"/"yes"/"on" case-insensitively as True for env_bool; comma-split for env_list). Used for DEBUG, ALLOWED_HOSTS, CORS_ALLOWED_ORIGINS, CSRF_TRUSTED_ORIGINS, SECURE_SSL_REDIRECT.
  • apps/projects/caching.py::project_statistics_cache_key(*, project_id) — a single-purpose cache-key builder, not a generic caching utility.
  • docker/entrypoint.sh's inline Python heredoc — a Postgres-readiness retry loop (30 attempts, 1s apart, 2s connect timeout) using dj_database_url + psycopg, run before exec "$@".

There is deliberately no general-purpose utils module — helper functions live next to the one thing that uses them.

Getting Started: Installation

Cloning the repo and installing dependencies with uv.

git clone https://github.com/Mayank170906/backend-dbms.git
cd backend-dbms
uv sync

uv sync reads pyproject.toml/uv.lock and creates a .venv with exactly the pinned dependency versions (72 pinned packages, direct + transitive). By default it also installs the dev dependency group (pytest and friends) — see Commands.

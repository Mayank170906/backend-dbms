Getting Started: Prerequisites

What you need installed before running the project locally.

  • Python 3.12 — pinned in .python-version. The project targets requires-python = ">=3.12" in pyproject.toml.
  • uv — the dependency manager used instead of pip/requirements.txt. Installs from pyproject.toml + uv.lock.
  • Docker + Docker Compose — needed only if you want to run via Running with Docker instead of a native setup.
  • PostgreSQL 16 — needed only for the native path; the Docker path provisions it for you via the db compose service (postgres:16-alpine).
  • Redis 7 — only required if you intend to exercise caching, Celery, or WebSocket features locally; the app degrades to not caching/broadcasting rather than crashing if it's unset, but Celery/Channels genuinely need it running. The compose redis service uses redis:7-alpine.
There is no requirements.txt in this repo — dependency state lives entirely in pyproject.toml and the committed uv.lock.

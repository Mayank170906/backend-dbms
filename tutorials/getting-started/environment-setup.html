Getting Started: Environment Setup

Configuring .env for local development.

cp .env.example .env

config/settings/base.py loads this file via python-dotenv at import time (without overriding any real environment variables already set). The variables that matter for a native (non-Docker) local run are:

VariableLocal dev value
DJANGO_SETTINGS_MODULEconfig.settings.development (also manage.py's own default)
DEBUGTrue
SECRET_KEYAny value — development.py falls back to a hardcoded insecure key if unset, so this is optional locally (never rely on that fallback anywhere but a laptop).
ALLOWED_HOSTSlocalhost,127.0.0.1 (the base default)
DATABASE_URLPoints at your local/native Postgres — see Database Setup
REDIS_URL / CELERY_BROKER_URL / CELERY_RESULT_BACKEND / CACHE_URL / CHANNELS_REDIS_URLOnly needed if running Redis-backed features locally

The full, authoritative variable reference (including production-only variables) is on Reference → Environment Variables.

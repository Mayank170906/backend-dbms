Getting Started: Running Locally

Running the Django dev server directly (no Docker).

uv run python manage.py runserver

manage.py defaults DJANGO_SETTINGS_MODULE to config.settings.development, so this runs with DEBUG=True and the permissive dev CORS/secret-key fallbacks described in Configuration.

This alone gives you the full HTTP API. If you also want background jobs, scheduled jobs, or WebSocket broadcasts working, you additionally need Redis running and, in separate terminals: 

uv run celery -A config worker --loglevel=info
uv run celery -A config beat --loglevel=info
The plain Django dev server (runserver) is WSGI-style but Daphne is registered first in INSTALLED_APPS specifically so Channels can override runserver to also serve WebSocket connections — you don't need a separate ASGI command for local dev.

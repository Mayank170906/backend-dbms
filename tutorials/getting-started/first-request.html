Getting Started: First Request

Register, log in, and make an authenticated API call.

Register

curl -X POST http://localhost:8000/api/v1/auth/register/ \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "email": "alice@example.com", "password": "ChangeMe123!"}'

Log in

curl -X POST http://localhost:8000/api/v1/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "ChangeMe123!"}'

Returns an access and refresh token pair.

Make an authenticated request

curl http://localhost:8000/api/v1/organizations/ \
  -H "Authorization: Bearer <access_token>"

Connect to a WebSocket feed

const ws = new WebSocket(
  `ws://localhost:8000/ws/notifications/?token=${accessToken}`
);
ws.onmessage = (event) => console.log(JSON.parse(event.data));

See API → Authentication for token lifetimes/rotation and API → Endpoints for the full route table.

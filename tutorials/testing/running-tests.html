Running Tests

The exact commands, and what they need to be reachable.

uv run pytest
uv run pytest --cov=apps
uv run pytest tests/test_workflow_transitions.py -v
  • Needs a reachable PostgreSQL (DATABASE_URL) — --reuse-db keeps a persistent test database across runs instead of recreating it every time.
  • The WebSocket test (test_websocket_consumers.py) needs asyncio_mode = "auto", already set in pyproject.toml — no extra flag required.
  • After changing a model, drop the stale test schema once with uv run pytest --create-db.

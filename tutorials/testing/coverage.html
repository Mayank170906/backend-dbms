Test Coverage

What the README reports, and what that figure actually covers.

The project's README states 78 tests and roughly 90% coverage. That figure is reported by the project as of when it was last written down there — this documentation hasn't independently re-measured it, and neither should you treat it as continuously verified without re-running: 

uv run pytest --cov=apps --cov-report=term-missing

Coverage is scoped by [tool.coverage.run] to source = ["apps"], explicitly omitting */migrations/* and */tests/* — so the percentage describes application code (models/views/serializers/services/signals), not generated migration files or the test suite measuring itself.

There is no CI job that runs this on every push and publishes the number anywhere automatically — see Current Status.

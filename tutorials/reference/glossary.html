BackendDBMS Docs

Reference: Glossary

Every term used across this documentation, defined once. Type to filter.

Activity Log
An immutable record of a significant action (who, what, when, on what object). Once written, a row can never be updated or deleted — enforced in the model itself, not just by convention.
ADR (Architecture Decision Record)
A short document capturing a specific architectural decision, its context, and its consequences — see ADRs.
ArrayField
A PostgreSQL-specific column type storing a list of values directly, without a separate join table. Used for WorkflowTransition.allowed_roles.
ASGI
Asynchronous Server Gateway Interface — the standard that lets one Python web server (Daphne, here) handle both regular HTTP requests and long-lived WebSocket connections.
Cache-Aside
A caching pattern: check the cache first; on a miss, compute the real answer and store it in the cache before returning. Used for project statistics.
Celery
A distributed task queue for Python. Runs code outside the request/response cycle — either on demand ("send this email") or on a schedule ("do this every day").
Celery Beat
Celery's scheduler process — it doesn't run jobs itself, it just pushes a job onto the queue at the right time for a worker to pick up.
Channel Layer
Django Channels' pub/sub abstraction, backed here by Redis — how one server process's WebSocket broadcast reaches every other process's open connections.
Django Channels
The library that extends Django to handle WebSocket connections (and other non-HTTP protocols) alongside its normal request/response handling.
DRF (Django REST Framework)
The library used to build this project's JSON API on top of Django — serializers, viewsets, permissions, pagination, filtering.
GenericForeignKey (GFK)
A Django field that can point at a row in any model, not just one specific model — used by ActivityLog.target and Notification.target.
GIN Index
Generalized Inverted Index — a PostgreSQL index type suited to values containing multiple components, like full-text search vectors and array columns.
IDOR (Insecure Direct Object Reference)
A vulnerability class where changing an id in a URL/request lets a user access another user's data. Prevented here by scoping every queryset to the caller's actual memberships.
JWT (JSON Web Token)
A signed, self-contained token used to authenticate API requests without a server-side session. This project uses a short-lived access token plus a longer, rotating refresh token.
Membership
The model recording that a user belongs to an organization (or project), and with what role.
Migration
A versioned, incremental description of a database schema change, generated and applied by Django so the database structure can evolve alongside the code.
N+1 Query
A performance bug where fetching N related objects triggers N additional database queries instead of one query that fetches everything together. Prevented with select_related/prefetch_related.
ORM (Object-Relational Mapper)
The layer that lets Python code query and manipulate the database using classes and methods instead of raw SQL — Django's ORM is used exclusively in this project.
PROTECT / SET_NULL / CASCADE
The three on_delete behaviors used for foreign keys in this project — respectively: block the delete, null out the reference, or delete the dependent row too. Chosen deliberately per relationship, never left at a default.
Service Layer
A per-app services.py module that owns business rules and validation, called by views, management commands, and other services alike — so a rule holds regardless of what triggered it.
SearchVectorField / SearchRank / SearchQuery
PostgreSQL full-text search primitives, exposed through Django's django.contrib.postgres.search module.
Serializer
A DRF class that converts between Python/model objects and JSON, and validates incoming data before it reaches the database.
Signal
A Django mechanism for running code automatically when a model event happens (e.g. post_save). Used here for cache invalidation and search-vector maintenance.
Throttling
DRF's rate-limiting mechanism, backed by the same Redis cache used for statistics — limits how many requests a client can make in a given window.
Transaction (transaction.atomic())
A database mechanism guaranteeing a group of writes either all succeed or all roll back together — never left half-applied.
Viewset
A DRF class that groups the logic for a whole resource (list, create, retrieve, update, delete) instead of writing a separate view function for each.
WebSocket
A persistent, two-way connection between client and server, used here for the live activity feed and notification stream.
Workflow / WorkflowState / WorkflowTransition
The three models that make a task's status pipeline configurable data rather than a hardcoded set of choices — an administrator defines the states and which transitions between them are legal, and for which roles.

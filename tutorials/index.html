Backend DBMS — Documentation Hub

A multi-tenant workflow & project management platform, documented from the actual source: what's implemented, how it's architected, and how it ships.

Backend DBMS is a self-contained, multi-tenant workflow & project management platform (a Jira/Linear/Trello-style tool) built to demonstrate production-grade Django backend engineering — REST APIs, relational data modeling, JWT auth, transactions, caching, async processing, and real-time updates over WebSocket.

Quick Start

git clone https://github.com/Mayank170906/backend-dbms.git
cd backend-dbms
uv sync
cp .env.example .env
uv run python manage.py migrate
uv run python manage.py runserver

Full walkthrough: Getting Started.

Technology Stack

Python 3.12 · Django 6.1 · Django REST Framework · djangorestframework-simplejwt · PostgreSQL 16 (Supabase in production) · Redis · Celery · Django Channels · Daphne · WhiteNoise · Docker · uv. Full detail, with why each is used: Technology Stack.

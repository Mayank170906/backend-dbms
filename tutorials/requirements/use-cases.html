Requirements: Use Cases

The system's major use cases, each mapped to the real service method that implements it.

UC-01 — Register and log in

Actor: Anonymous visitor. Precondition: none. Main flow: POST register/ creates a User; POST login/ returns an access+refresh token pair. Exception: duplicate email/username → 400. Postcondition: caller holds a valid JWT. Implementation: RegisterView, LoginView.

UC-02 — Create an organization

Actor: Any authenticated user. Main flow: POST organizations/ creates the org and an OWNER membership for the caller. Implementation: OrganizationService.create_organization.

UC-03 — Create a project

Actor: Organization member. Precondition: caller is a member of the target organization. Main flow: POST projects/ creates the project and a MANAGER membership for the caller. Exception: non-member → 403 (checked before creation). Implementation: ProjectService.create_project.

UC-04 — Configure a workflow

Actor: Organization member. Main flow: create a Workflow, add ordered WorkflowStates, add role-gated WorkflowTransitions between them. Exception: an unknown role in allowed_roles → rejected. Implementation: WorkflowService.create_workflow/add_state/add_transition.

UC-05 — Create, assign, and transition a task

Actor: Project member. Main flow: create the task; assign a project member; transition it along a defined WorkflowTransition the caller's role is permitted to use. Exception: transitioning to a non-adjacent state, or with an insufficient role → rejected. Postcondition: an ActivityLog row and a Notification exist. Implementation: TaskService.create_task/assign, WorkflowService.transition_task.

UC-06 — Comment and mention

Actor: Project member. Main flow: POST a comment on a task; any @username mention of an actual project member triggers a notification. Exception: mentioning a non-member or nonexistent username → no notification sent; mentioning yourself → no notification. Implementation: CommentService.add_comment/_notify_mentions.

UC-07 — Export a project's tasks

Actor: Project manager. Main flow: POST {id}/export/ immediately returns 202 with a ProjectExport row; a Celery task generates the CSV and notifies the requester when done. Implementation: export_project_tasks_csv.

UC-08 — Search across projects, tasks, and comments

Actor: Any authenticated user. Main flow: GET search/?q= returns ranked matches from all three models, each pre-filtered to the caller's actual memberships. Implementation: SearchView.

Requirements: Actors

Every user class and role in the system, org-level and project-level.

Organization-level roles (Membership.role)

RoleDescription
OWNERCreated the organization. Set automatically by OrganizationService.create_organization.
ADMINManages membership and organization settings, alongside OWNER.
MEMBERDefault role for an invited user; can create projects.
VIEWERRead-only access at the organization level.

Project-level roles (ProjectMembership.role)

RoleDescription
MANAGERFull control within the project, including whichever workflow transitions are role-gated to MANAGER.
DEVELOPERCreates and edits tasks and comments, and moves tasks through transitions permitted to DEVELOPER.
VIEWERRead-only access at the project level.

Unauthenticated

Can reach only register/, login/, login/refresh/, and the two password-reset/* endpoints — every other route requires a valid JWT (DRF's global IsAuthenticated default).

See Codebase → Permissions for exactly how these roles are checked.

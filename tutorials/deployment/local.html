Deployment: Local

Running without Docker — uv, a native Postgres, and optionally native Redis.

This is the same path as Getting Started → Running Locally; this page frames it as one of four deployment targets rather than a first-time setup walkthrough.

uv sync
cp .env.example .env   # point DATABASE_URL at your local Postgres
uv run python manage.py migrate
uv run python manage.py runserver

Adequate for exercising the HTTP API. Celery/Channels/caching need Redis running natively too, plus celery -A config worker / beat in separate terminals.

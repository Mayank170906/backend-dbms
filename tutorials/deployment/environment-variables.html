Deployment: Environment Variables

Which variables matter in which environment — the exhaustive reference lives under Reference.

The complete variable-by-variable reference (purpose, required, sensitive, used-by) is on Reference → Environment Variables. This page is the short, deployment-context version.

EnvironmentSourceDistinguishing variables
Local (native).env, from .env.exampleDJANGO_SETTINGS_MODULE=config.settings.development, permissive defaults
Docker Compose (dev)x-app-env anchor in docker-compose.yml + .envDATABASE_URL/REDIS_URL point at the db/redis service names
Docker Compose (prod).env.production, from .env.production.exampleDJANGO_SETTINGS_MODULE=config.settings.production
RenderRender Dashboard → EnvironmentDATABASE_URL points at Supabase, not a compose service name; ALLOWED_HOSTS includes the Render hostname

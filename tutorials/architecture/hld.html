High-Level Design

The system's major components and how they talk to each other.

Four layers: a browser client, one Django application process that owns both the REST API and the WebSocket layer, PostgreSQL as the only system of record, and Redis-backed asynchronous processing (Celery worker + beat) for anything that shouldn't block a request/response cycle.

One deployable Django image serves three roles (web/worker/beat) depending only on its container command — see Deployment → Docker.

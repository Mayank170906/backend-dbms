Register, login, authenticated request, refresh, logout — step through the real JWT lifecycle.

Step through the five real stages of the JWT lifecycle, from apps/accounts/api/views.py and SIMPLE_JWT settings.

Access tokens last 30 minutes; refresh tokens last 7 days and rotate on every use, with the old one blacklisted (ROTATE_REFRESH_TOKENS + BLACKLIST_AFTER_ROTATION).

A daily Celery beat job (cleanup_expired_tokens, 03:00) runs Django's flushexpiredtokens management command to prune the blacklist tables — see Services.

WebSocket authentication is a separate path

A browser can't set a custom header during a WebSocket handshake, so ws/projects/<id>/ and ws/notifications/ connections authenticate via a ?token= query parameter, validated by the custom JWTAuthMiddleware in config/channels_auth.py rather than DRF's JWTAuthentication. See Developer Notes → Authentication Notes.

Transition a task

POST /api/v1/tasks/87/transition/
{ "to_state_id": 9 }
200 OK
{ "id": 87, "workflow_state": 9, ... }

Rejected with 400 if state 9 isn't reachable from the task's current state via a defined WorkflowTransition, or 403 if the caller's project role isn't in that transition's allowed_roles.

Request a project export

  "error_message": "",

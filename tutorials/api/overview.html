API Overview

Base path, format, pagination, filtering, throttling, and schema.

  • Base path: /api/v1/.
  • Format: JSON. In production the browsable API is disabled — DEFAULT_RENDERER_CLASSES is overridden to ["rest_framework.renderers.JSONRenderer"] only.
  • Pagination: PageNumberPagination, PAGE_SIZE = 20.
  • Filtering: DjangoFilterBackend (per-viewset filterset_fields/filterset_class) + SearchFilter + OrderingFilter.
  • Throttling: UserRateThrottle (1000/day) and AnonRateThrottle (100/day) globally, plus a scoped auth throttle (20/hour) on register/login/password-reset.
  • Schema: drf-spectacular generates an OpenAPI schema at /api/schema/, browsable at /api/docs/ (Swagger UI). SERVE_INCLUDE_SCHEMA: False.
  • Error shape: a custom exception handler wraps every error — see Error Handling.
